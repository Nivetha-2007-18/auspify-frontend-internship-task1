# Task 1 (Easy): Responsive Landing Page

**Program:** Auspify Technologies, Frontend Developer Internship
**Project:** FocusFlow, a landing page for a student study-planner app (sample product)

## How to run
Keep `index.html`, `style.css` and `script.js` in the same folder, then double-click `index.html` to open it in any modern browser. No installation needed.

## Files
| File | Purpose |
|---|---|
| `index.html` | Page structure (HTML5, semantic tags) |
| `style.css` | Styling, layout and responsive design (CSS3) |
| `script.js` | Mobile menu, scroll effects, typing effect, counters, form validation |
| `screenshots/` | Desktop and mobile screenshots of the finished page |

## Task workflow completed
1. Page structure created with HTML5.
2. Layout styled with CSS (Grid, Flexbox, custom properties).
3. Responsive design with breakpoints at 992px, 768px and 560px.
4. Navigation bar and call-to-action sections added.
5. Optimized for mobile and desktop.

## Key features
- Responsive layout
- Sticky navigation bar with a mobile hamburger menu
- Hero section with typing headline and animated stats
- Features, How It Works, Reviews and Pricing sections
- Call-to-action with email validation
- Mobile-friendly design with reduced-motion support

## Skills used
HTML5, CSS3, Responsive Design, UI Development, basic JavaScript
